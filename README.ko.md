# 최소송금 N빵 계산기 (MoneySplit / Wire-Min-Splitter)

`npm run build` 후 `npm run preview`를 실행하고 <http://127.0.0.1:8080>을 여세요.

이 앱은 정적 웹사이트와 설치형 PWA입니다. 정산은 브라우저 안에서 계산하며 이름과 금액을 계산 서버로 보내지 않습니다. 첫 로드가 성공하면 오프라인에서도 사용할 수 있습니다. 데스크톱 설치에는 지원 브라우저가 필요합니다. Tauri 설치 파일은 이후 작업입니다.

## 정산 규칙

- 지출을 균등 분할하고 추가 지급/수령을 반영합니다. 원본 추가 지급 합계와 추가 수령 합계는 정확히 같아야 합니다.
- 금액과 배율은 정확한 소수로 계산합니다. 최종 순잔액을 센트 단위로 배분하여 합계를 0으로 유지합니다. 동일 입력끼리도 1센트 차이가 날 수 있습니다. 동률은 이름으로 결정합니다.
- 원래값은 배율 적용 전 금액으로 독립 계산합니다. 배율 적용 결과를 다시 나누어 복원하지 않습니다.
- 송금 수를 먼저 최소화하고, 동률이면 미선택 송금자의 다중 송금 부담을 줄입니다. 엄격 모드에서는 선택한 사람만 여러 건을 보낼 수 있습니다.
- 최소 송금 탐색은 조합이 많아 오래 걸릴 수 있습니다. 자동 시간 제한은 없으며 **취소**로 중단할 수 있습니다. 센트 이외 단위의 표시는 근삿값입니다.

## 배포와 검증

Node.js 22 이상에서 `npm ci`, `npm test`, `npm run build`를 실행하세요. Cloudflare Pages에서 프레임워크 **None**, 빌드 명령 **npm run build**, 출력 폴더 **dist**를 설정하세요. 무료 제공 주소로 공개할 수 있습니다. 별도 도메인은 등록·갱신 비용이 있습니다.

Python은 참고 구현과 선택적 로컬 API로 남아 있습니다. 프로젝트 `.venv`에서 `uv sync --extra test`, `uv run pytest`를 사용하세요.

정확한 계약, 배포 절차, 검증 명령은 [영문 README](README.md)를 참조하세요. 이전의 동일 입력 강제 정규화 규칙은 균형 센트 배분으로 변경되었습니다.
