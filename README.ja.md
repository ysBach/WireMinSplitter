# 最小送金バラバラ割り勘 (MoneySplit / Wire-Min-Splitter)

`npm run build`、`npm run preview`を実行し、<http://127.0.0.1:8080>を開いてください。

静的サイトとインストール可能なPWAです。精算をブラウザー内で計算するため、名前と金額を計算サーバーに送信しません。最初の読み込みが成功するとオフラインでも使えます。デスクトップへのインストールには対応ブラウザーが必要です。Tauri版は後の作業です。

## 精算ルール

- 支出を均等に分け、追加支払・受取を反映します。元の追加支払合計と追加受取合計は正確に一致する必要があります。
- 金額と倍率は正確な小数で計算します。最終純残高をセントに配分し、合計をゼロに保ちます。同じ入力でも1セント異なる場合があります。同率は名前で決定します。
- 元の値は倍率適用前の金額で独立して計算します。変換後の送金を倍率で割って復元しません。
- 送金数を最小化し、同率なら未選択の支払者の複数送金を減らします。厳格モードでは選択した人だけが複数送金できます。
- 最小送金探索は組み合わせが多く、時間がかかる場合があります。自動時間制限はありません。**キャンセル**で停止できます。セント以外の表示単位は近似表示です。

## 配信と検証

Node.js 22以降で`npm ci`、`npm test`、`npm run build`を実行してください。Cloudflare Pagesでフレームワーク**None**、ビルドコマンド**npm run build**、出力ディレクトリー**dist**を指定します。無料の提供URLで公開できます。独自ドメインには登録・更新料金があります。

Pythonは参照実装と任意のローカルAPIです。プロジェクトの`.venv`で`uv sync --extra test`、`uv run pytest`を使います。

仕様、配信手順、検証コマンドの詳細は[英語README](README.md)を参照してください。従来の同一入力の強制正規化は、合計を保存するセント配分に変更しました。
